# Changelog

## 0.2.0 - 2026-09-27

- Pause Unity Analytics initialization when the KSP addon starts.
- Continue forcing Analytics events and device statistics off.
- Include initialization state in the status log.

## 0.1.0 - 2026-09-27

- Initial KSP 1.12.5 Windows x64 release.
- Disable Unity Analytics events and device statistics at startup.
- Reapply disabled state on focus and with a two-second watchdog.
